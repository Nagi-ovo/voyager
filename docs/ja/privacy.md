# プライバシーポリシー

最終更新日：2026年9月7日

## はじめに

Voyager（以下「本拡張機能」）は、お客様のプライバシー保護に努めています。本プライバシーポリシーでは、本ブラウザ拡張機能がどのように情報を収集・利用・保護するかについて説明します。

## データの収集と使用

**本拡張機能では個人情報を一切収集しません。**

Voyager は、完全にお客様のブラウザ内でローカルに動作します。拡張機能が生成・管理するすべてのデータ（フォルダ、プロンプトテンプレート、スター付きメッセージ、設定など）は、以下の場所に保存されます：

1. お客様のローカルデバイス（`chrome.storage.local`）
2. ブラウザの同期ストレージ（`chrome.storage.sync`、利用可能な場合）。これにより、デバイス間で設定が同期されます。

開発者は、お客様の個人データ、チャット履歴、その他のプライバシー情報には一切アクセスできません。また、閲覧履歴を追跡することもありません。

## Google ドライブ同期（オプション）

Google ドライブ同期を明示的に有効にした場合、Chrome・Edge・Firefox ではブラウザの Identity API、Safari 直装版ではネイティブ Google Sign-In を使用し、認証情報は macOS キーチェーンに保存されます。どちらも `drive.file` スコープのみを要求し、データは端末と**お客様自身の Google ドライブ**の間で直接転送されます。OAuth トークンが Voyager のサーバーへ送信されることはありません。

## プラグインカタログのオンライン更新（オプション）

プラグインを 1 つ以上有効にしているサイトでは、Voyager がそのサイト用のカタログファイルを HTTPS で取得することがあります（`https://voyager.nagi.fun/catalog/hosts/<サイトのホスト名>.json`、例：`https://voyager.nagi.fun/catalog/hosts/chat.deepseek.com.json`）。取得は該当ページを開いたとき、またはそのページで拡張機能のポップアップを開いたときだけ行われ、前回のチェックからお客様が選んだ間隔（既定は 6 時間。1 時間・6 時間・24 時間・手動のみから選択）が経過している場合に限られます。Gemini と AI Studio のページにはプラグインがないため、リクエストは一切発生しません。リクエストは通常の GET で、Cookie もアカウント識別子も拡張機能の識別子も送信せず、ページやチャットの内容も送信しません。一般的なウェブリクエストと同様に、サーバーからはリクエスト元の IP アドレスとブラウザのユーザーエージェント、および URL のパスに含まれるサイトのホスト名が見えます。プラグインのあるサイトでは、ポップアップに「プラグインのオンライン更新」スイッチとチェック間隔の選択肢があり、どちらもブラウザの同期ストレージに保存され、設定のバックアップにも含まれます。スイッチをオフにすると、「今すぐプラグインの更新を確認」を押したとき以外は voyager.nagi.fun に接続しません。取得に失敗した場合や、そのサイトのカタログファイルが存在しない場合は、拡張機能に同梱されたプラグインのスナップショットがそのまま使われます。取得されるカタログは CSS と JSON のみで、使用前に検証とサニタイズが行われます。JavaScript をダウンロードすることも実行することもありません。voyager.nagi.fun は Cloudflare プロキシ配下の静的ホスティングです。Voyager プロジェクトはこれらのリクエストを記録・保存せず、接続メタデータ（IP アドレス、User-Agent）はホスティング事業者がそれぞれのプライバシーポリシーに基づいて扱います。

## 権限について

本拡張機能は、機能維持に必要な最小限の権限のみを申請します：

- **Storage（ストレージ）**：設定、フォルダ、プロンプト、スター付きメッセージ、UI カスタマイズオプションをローカルおよびデバイス間で保存するために使用します。
- **Identity（認証）**：オプションの Google ドライブ同期機能の Google 認証に使用します。クラウド同期を明示的に有効にした場合のみ使用されます。
- **Scripting（スクリプト注入）**：Gemini ページおよびユーザーが指定したカスタムウェブサイトにコンテンツスクリプトを動態的に注入するために使用します（プロンプトマネージャー機能）。拡張機能自身にバンドルされたスクリプトのみが注入され、リモートコードの取得や実行は行いません。
- **Host Permissions（ホスト権限）**（gemini.google.com、aistudio.google.com など）：Gemini UI を拡張するコンテンツスクリプトを注入するために使用します（フォルダ、エクスポート、タイムライン、引用返信など）。Google 関連ドメイン（googleapis.com、accounts.google.com）は Google ドライブ同期の認証に必要です。
- **Optional Host Permissions（オプションのホスト権限）**（すべての URL）：プロンプトマネージャーのカスタムウェブサイトを明示的に追加した場合のみ、ランタイムでリクエストされます。ユーザーの操作なしに有効化されることはありません。

## 第三者サービス

本拡張機能が、第三者サービス、広告主、または分析プロバイダーとデータを意図的に共有することはありません。唯一の例外は、上記のとおりユーザー自身が有効化または実行する通信（Google Drive 同期、プラグインカタログの更新など）で、該当するサービス事業者またはホスティング事業者が、接続メタデータ（IP アドレス、User-Agent）を自社のプライバシーポリシーに従って処理する場合があります。

## ポリシーの変更

プライバシーポリシーは随時更新される可能性があります。変更があった場合は、このページに新しいプライバシーポリシーを掲載することで通知します。
