# Activity：把注意力留給正在進行的對話

資料夾回答「這段對話放在哪裡」。累積的內容愈來愈多時，另一個問題會經常出現：現在該先看什麼？

Activity 是資料夾之上的時間檢視。點擊 **Folders** 右側的鈴鐺，原本的目錄會暫時換成一組依照真實對話活動排列的對話。資料夾結構、對話歸屬和 Star 狀態都不會被改動。

**設計靈感：** 這個檢視的設計靈感來自 OpenAI 的 Codex / ChatGPT Desktop 側邊欄。Voyager 沿用「先顯示近期仍在活動的對話」的思路，再把它改造成 Gemini 資料夾之上的時間檢視。

## Priority（優先）會隨對話活動變化

優先群組收集最近 **3 小時**內有新對話輪次的對話。這裡讀取的是實際對話時間，不是開啟或查看時間。

一段對話進入優先群組後，不會同時出現在今天。3 小時的活躍時段結束時，Activity 會自動把它放回今天或對應的日期群組，不需要手動重新整理。

Star 仍然保留，但它是一個獨立的手動標記。將對話加上 Star 不會讓它進入優先群組，移除 Star 也不會讓正在活躍的對話離開優先群組。

## 只呈現最近幾天

優先群組下方依序是 Today（今天）、Yesterday（昨天），以及前幾個自然日的星期名稱。Activity 只涵蓋今天和之前四個自然日，讓清單保持在目前工作的範圍內。

更早的對話和時間未知的舊記錄不會出現在這裡，但它們沒有被隱藏或刪除。再次點擊鈴鐺回到資料夾樹，仍然可以在原本的位置找到它們。

## 同一段對話只出現一次

一段對話可以屬於多個資料夾。Activity 會把這些參照合併成一筆記錄，並在標題下方保留資料夾名稱。將滑鼠停在資料夾資訊上，可以查看完整路徑。

這樣能避免同一段對話在優先或今天群組中重複佔用注意力，同時保留它所屬專案的脈絡。

## 三種訊號各有用途

| 訊號     | 依據                 | 適合回答的問題             |
| -------- | -------------------- | -------------------------- |
| 資料夾   | 手動整理的專案與主題 | 這段對話屬於哪裡？         |
| Activity | 最近一次真實對話時間 | 最近有哪些工作仍在進行？   |
| Star     | 手動標記             | 哪些對話需要長期保留標記？ |

資料夾適合從已累積的內容中尋找資料，Activity 則縮小每次回到 Gemini 時需要重新判斷的範圍。可以先接續優先群組中仍有脈絡的對話，再處理今天或昨天；需要舊資料時，再切回完整的資料夾樹。
