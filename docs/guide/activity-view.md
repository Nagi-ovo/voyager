# Activity：把注意力留给正在发生的对话

文件夹回答「这段对话放在哪里」。当积累的内容越来越多，另一个问题会反复出现：此刻该先看什么？

Activity 是文件夹之上的时间视图。点击 **Folders** 右侧的铃铛，原来的目录会暂时换成一组按真实对话活动排列的会话。文件夹结构、对话归属和 Star 状态都不会被改动。

**设计灵感：** 这个视图的设计灵感来自 OpenAI 的 Codex / ChatGPT Desktop 侧边栏。Voyager 沿用了「先显示近期仍在活动的对话」这一思路，再把它改造成 Gemini 文件夹之上的时间视图。

## Priority（优先）跟着对话活动变化

优先分组收集最近 **3 小时**内有新对话轮次的会话。这里读取的是实际对话时间，不是打开或查看时间。

一段对话进入优先分组后，不会同时出现在今天。3 小时的活跃窗口结束时，Activity 会自动把它放回今天或对应的日期分组，不需要手动刷新。

Star 仍然保留，但它是一条独立的手动标记。给对话加星不会让它进入优先分组，取消 Star 也不会让正在活跃的对话离开优先分组。

## 只呈现最近几天

优先分组下面依次是 Today（今天）、Yesterday（昨天），以及此前几个自然日的星期名称。Activity 只覆盖今天和此前四个自然日，让页面保持在适合回到当前工作的范围内。

更早的对话和时间未知的旧记录不会出现在这里，但它们没有被隐藏或删除。再次点击铃铛回到文件夹树，仍然可以按原来的目录找到它们。

## 同一段对话只出现一次

一段对话可以属于多个文件夹，Activity 会把这些引用合并成一条记录，并在标题下方保留文件夹名称。鼠标停在文件夹信息上时，可以查看完整路径。

这避免了同一段对话在优先或今天分组中重复占据注意力，同时不丢失它属于哪些项目的上下文。

## 三种信号各有用途

| 信号     | 依据                 | 适合回答的问题             |
| -------- | -------------------- | -------------------------- |
| 文件夹   | 手动整理的项目与主题 | 这段对话属于哪里？         |
| Activity | 最近一次真实对话时间 | 最近有哪些工作仍在推进？   |
| Star     | 手动标记             | 哪些对话需要长期保留标记？ |

文件夹适合检索已经积累的内容，Activity 则缩小每次回到 Gemini 时需要重新判断的范围。打开铃铛后，可以先接上优先分组中仍有上下文的对话，再处理今天或昨天；需要查旧资料时，再切回完整的文件夹树。
