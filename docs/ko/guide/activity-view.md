# Activity: 진행 중인 대화에 주의를 두기

폴더는 대화를 어디에 둘지 정리합니다. 대화가 쌓일수록 지금 무엇을 먼저 봐야 하는지도 자주 판단하게 됩니다.

Activity는 폴더 위에 겹쳐 보는 시간 기반 화면입니다. **Folders** 오른쪽의 종을 클릭하면 폴더 트리 대신 실제 대화 활동순으로 정렬된 목록이 나타납니다. 폴더 구조, 대화가 속한 위치, Star 상태는 바뀌지 않습니다.

**디자인 영감:** 이 화면은 OpenAI의 Codex / ChatGPT Desktop 사이드바에서 영감을 얻었습니다. Voyager는 최근까지 활동 중인 대화를 먼저 보여 주는 방식을 이어받아 Gemini 폴더 위에 겹쳐 보는 시간 기반 화면으로 바꿨습니다.

## 우선순위(Priority)는 최근 대화에 따라 바뀝니다

우선순위에는 최근 **3시간** 안에 새 대화 턴이 생긴 대화가 들어갑니다. 대화를 열거나 확인한 시간이 아니라 실제로 대화한 시간을 사용합니다.

우선순위에 들어간 대화는 오늘에 중복해서 표시되지 않습니다. 3시간의 활동 구간이 끝나면 Activity가 자동으로 오늘 또는 해당 날짜 그룹으로 돌려보냅니다. 페이지를 새로 고칠 필요가 없습니다.

Star는 별도의 수동 표시로 남습니다. Star를 추가해도 우선순위로 이동하지 않으며, Star를 지워도 활동 중인 대화가 우선순위에서 빠지지 않습니다.

## 최근 며칠만 보여 줍니다

우선순위 아래에는 오늘(Today), 어제(Yesterday), 그 이전 날짜의 요일이 차례로 나타납니다. Activity는 오늘과 이전 4일만 다뤄 현재 작업에 가까운 목록을 유지합니다.

그보다 오래된 대화와 활동 시간이 없는 이전 기록은 이 화면에 나타나지 않습니다. 숨겨지거나 삭제된 것은 아닙니다. 종을 다시 클릭해 폴더 트리로 돌아가면 원래 위치에서 찾을 수 있습니다.

## 한 대화는 한 번만 표시됩니다

같은 대화가 여러 폴더에 속할 수 있습니다. Activity는 해당 항목들을 한 줄로 합치고 제목 아래에 폴더 이름을 남깁니다. 폴더 정보에 마우스를 올리면 전체 경로를 확인할 수 있습니다.

같은 대화가 우선순위나 오늘의 여러 자리를 차지하지 않으면서도 어느 프로젝트에 속하는지는 유지됩니다.

## 세 가지 신호의 역할

| 신호     | 기준                        | 답하는 질문                      |
| -------- | --------------------------- | -------------------------------- |
| 폴더     | 직접 정리한 프로젝트와 주제 | 이 대화는 어디에 속하는가?       |
| Activity | 마지막 실제 대화 시간       | 최근까지 진행된 작업은 무엇인가? |
| Star     | 수동 표시                   | 오래 표시해 둘 대화는 무엇인가?  |

폴더는 쌓인 자료를 다시 찾을 때 유용합니다. Activity는 Gemini로 돌아올 때마다 다시 판단할 대화의 수를 줄입니다. 우선순위에서 흐름이 남아 있는 대화를 이어서 보고, 오늘이나 어제로 이동한 뒤 오래된 자료가 필요할 때 전체 폴더 트리로 돌아갈 수 있습니다.
