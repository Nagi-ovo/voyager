# DeepSeek Harness

DeepSeek이 직접 만든 오픈소스 코딩 agent. 내 컴퓨터에서 돌아갑니다.

웹 화면이 있고, 주소는 `localhost:3080`입니다.

웹 화면이 있다는 건, Voyager가 들어갈 수 있다는 뜻입니다.

## 왜 되는가

Voyager의 프롬프트 관리자는 도메인을 보지 않습니다. 당신이 추가한 사이트만 봅니다.

로컬 주소도 사이트입니다.

그래서 DeepSeek Harness도 Gemini, Claude, ChatGPT와 다르지 않습니다. 프롬프트가 따라갈 자리가 하나 더 생길 뿐입니다.

## 세 단계

### 1. DSH 실행하기

```bash
npm i -g @deepseek-ai/dsh
dsh web
```

브라우저에서 `http://localhost:3080`을 엽니다.

### 2. 팝업에서 스위치 켜기

![도구 모음의 퍼즐 아이콘을 클릭하고, Voyager를 클릭한 다음, localhost:3080에서 프롬프트 관리자 켜기](/assets/dsh-enable-steps-en.png)

지금 보고 있는 페이지가 `localhost:3080`이니, 팝업 맨 위에 그 항목이 바로 뜹니다. 켜고, 접근을 허용하면 됩니다.

주소를 직접 칠 일은 없습니다.

### 3. 페이지 새로고침

플로팅 버튼이 오른쪽 아래에 나타납니다.

![DeepSeek Harness 안에서 실행 중인 프롬프트 관리자](/assets/prompt-manager-deepseek-harness.png)

## 어디서나 같은 라이브러리

사이트마다 라이브러리가 따로 생기지 않습니다. 라이브러리는 하나뿐이고, 그것이 당신을 따라다닙니다.

Gemini, Claude, ChatGPT에서 저장한 프롬프트는 DSH를 여는 순간 이미 거기 있습니다. 하나도 빠짐없이. 반대도 마찬가지입니다. DSH 안에서 쓴 프롬프트는 Gemini로 돌아가면 그대로 기다리고 있습니다.

태그도, 즐겨찾기도, 검색도 전부 같습니다.

![하나의 라이브러리가 모든 화면에 닿는 모습](/assets/one-prompt-library.png)

## 몇 가지 참고

**포트는 고정이 아닙니다.** DSH는 아직 개발자 프리뷰라 기본 포트가 바뀔 수 있습니다. 바뀌면 새 포트로 다시 추가하면 됩니다.

**프롬프트 관리자만 로드됩니다.** 타임라인, 폴더 같은 기능은 Gemini용으로 만들어져서 사용자 지정 사이트에서는 실행되지 않습니다.

**프롬프트는 이 컴퓨터를 떠나지 않습니다.** DSH도 로컬, Voyager의 라이브러리도 로컬. 전 구간이 밖으로 나가지 않습니다.

::: tip
같은 방법이 모든 로컬 Web UI에 통합니다 — Open WebUI, LibreChat, 직접 만든 그것까지. 주소를 넣고, 새로고침하면 끝입니다.
:::
