# DeepSeek Harness

Официальный agent DeepSeek для написания кода, с открытым исходным кодом. Работает на вашей машине.

У него есть веб-интерфейс по адресу `localhost:3080`.

Веб-интерфейс — значит, Voyager сможет туда попасть.

## Почему это работает

Менеджер промптов Voyager не смотрит на домены. Он смотрит на сайты, которые вы добавили.

Локальный адрес — тоже сайт.

Поэтому DeepSeek Harness ничем не отличается от Gemini, Claude или ChatGPT — просто ещё одно место, куда за вами следуют промпты.

## Три шага

### 1. Запустите DSH

```bash
npm i -g @deepseek-ai/dsh
dsh web
```

Откройте `http://localhost:3080` в браузере.

### 2. Включите переключатель во всплывающем окне

![Нажмите значок пазла на панели инструментов, нажмите Voyager и включите Менеджер промптов на localhost:3080](/assets/dsh-enable-steps-en.png)

Вы уже на `localhost:3080`, поэтому всплывающее окно предлагает этот пункт первым. Включите его и дайте доступ.

Адрес вводить не нужно.

### 3. Перезагрузите страницу

Плавающая кнопка появится в правом нижнем углу.

![Менеджер промптов внутри DeepSeek Harness](/assets/prompt-manager-deepseek-harness.png)

## Одна библиотека — везде

У вас не появляется отдельная библиотека на каждый сайт. У вас одна библиотека, и она следует за вами.

Каждый промпт, сохранённый в Gemini, Claude или ChatGPT, уже на месте, когда вы открываете DSH. Все до одного. Работает и в обратную сторону: напишите промпт внутри DSH — он будет ждать вас в Gemini.

Те же теги, то же избранное, тот же поиск.

![Одна библиотека, которая доходит до каждого интерфейса](/assets/one-prompt-library.png)

## Несколько замечаний

**Порт не зафиксирован.** DSH всё ещё предварительная версия для разработчиков, порт по умолчанию может измениться. Если это произойдёт, просто добавьте новый.

**Загружается только Менеджер промптов.** Таймлайн, Папки и остальное сделаны для Gemini и на пользовательском сайте не запускаются.

**Ваши промпты не покидают машину.** DSH локальный, библиотека Voyager локальная. Вся цепочка остаётся внутри.

::: tip
Тот же способ работает с любым локальным веб-интерфейсом — Open WebUI, LibreChat, тем, который вы написали сами. Добавьте адрес, перезагрузите, готово.
:::
